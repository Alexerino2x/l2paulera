# l2paulera

Servidor privado de Lineage 2 **Gracia Final** (CT2.3) para jogar com os amigos, sem monetização.

Foco: sandbox enxuto (performance) e eventos no estilo battleground (TvT, Deathmatch, Last Man Standing, Capture the Flag), com inscrição pela cidade, rank por tipo de evento e loja paga com pontos de rank.

O código do servidor entra por pull request (ver PRs abertos).
